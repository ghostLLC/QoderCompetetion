## 二、作品是什么

**斗图军火库**：上传一张照片，3 分钟造出一整套原创表情包。

- **一键抠图**：人物、宠物、物件都能自动抠出来，全程在你的浏览器本地完成，照片不上传服务器。
- **模板编辑**：6 套视觉模板（经典梗图 / 荧光弹亮 / 危险警示 / 气泡吐槽 / 手账拼贴 / 心动暴击）、22 个矢量贴纸、60 条原创文案，拖拽即可排版。
- **整套生成**：选一个情绪主题（宿舍生存 / 班级群日常 / 打工人 / 无语合集 / 求求了 / 吃喝玩乐），一次生成 10 张，可单张换文案。
- **一键带走**：单张 1080×1080 透明底 PNG，或整套 ZIP 打包下载。
- **零注册、零上传、零埋点**：打开就能用；草稿只存在本机 IndexedDB。

## 三、为什么做

斗图是大学群里最日常的社交方式，但我们自己的照片往往只能"躺"在相册里：

1. **网图不合用**：搜来的表情包千篇一律，跟自己的梗、自己的群对不上。
2. **不会 PS**：想给室友的丑照配个字，传统修图软件学习成本太高。
3. **工具只做单张**：现有梗图工具大多是"做一张、导一张"，没有"一整套"的概念，斗图时根本不够用。
4. **隐私顾虑**：很多在线抠图要上传照片，谁愿意把室友的丑照传到别人服务器上？

所以我想做一个**把"做表情包"变成流水线**的工具：上传一次，抠图一次，选个主题，直接出一个"军火库"级别的整套弹药。数据不出浏览器，是产品原则，也是技术选择。

## 四、怎么用（5 步）

1. 打开链接，点「拿这个玩玩」用示例照片体验，或上传自己的照片。
2. 等待本地抠图（进度可见，也可以跳过，进入相框模式）。
3. 选模板、改文案、加贴纸，拖拽调整位置。
4. 选一个情绪主题，一键生成 10 张九宫格，单格可换文案。
5. 导出单张透明底 PNG，或整套 ZIP 打包下载，发群里开斗。

## 五、怎么用 Qoder 做出来的

这个作品从想法到上线，全程在 Qoder 里完成：

1. **需求与设计**：先让 Qoder 读比赛页、梳理赛道评分标准，再用头脑风暴流程把"表情包工厂"从模糊想法收敛成设计文档：用户、核心流程、功能范围、视觉方向、风险与降级路径。设计文档和实现计划都在仓库里可查。
2. **技术方案对比**：抠图最初考虑 @imgly/background-removal，但它的自托管数据包有 285MB，不适合"评委点开就能用"。最后选择 **u2netp ONNX（4.6MB）+ onnxruntime-web**，模型、WASM 全部自托管，单线程 WASM，不依赖任何外部 API。
3. **按计划实现**：把 17 个任务拆成"脚手架 → 场景模型 → 中文文字排版 → 内容库 → 共享 Canvas 渲染器 → 抠图 → Konva 编辑器 → 面板与创建流程 → 整套生成 → ZIP → 草稿持久化 → 首页 → 响应式/无障碍 → 验收"，每个任务都先写测试、再实现、再用浏览器验证。Qoder 的代码代理负责实现，我负责审阅和拍板；测试从 1 个涨到 172 个。
4. **用浏览器验收**：用 Chrome DevTools MCP 实际走真实流程——上传、抠图、编辑、导出、打包、手机视口、模型加载失败降级，并用 Lighthouse 把无障碍做到 100。QA 过程中修掉了几个真实问题，比如键盘在底部标签栏按方向键会误移动画布元素、取色器会刷屏撤销栈、导航中断抠图会进入未加相框的编辑器。
5. **部署**：用 Qoder Sites 直接发布公网链接，评委点开即可访问；模型和字体都跟随站点托管，不依赖外部 CDN。

**几个值得一提的设计**：

- **共享渲染器**：编辑器的 Konva 画布和导出/缩略图共用同一套排版与绘制几何，保证"所见即所得"。
- **中文字体自适应**：按字符测量、自动降字号、最多两行、放不下时省略号，避免梗图文字溢出。
- **降级优先**：模型下载/推理失败时一键进入相框模式，依然能编辑和导出。
- **隐私即架构**：没有后端；图片、蒙版、草稿都只留在浏览器里。
